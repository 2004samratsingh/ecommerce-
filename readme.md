# 🛒 TechStore - E-Commerce Web Application

A lightweight, responsive, and dynamic single-page E-Commerce web application built using fundamental web technologies: **HTML5**, **CSS3**, and **Vanilla JavaScript**. This project demonstrates dynamic DOM manipulation, responsive layout design, and cart state management without external libraries.
